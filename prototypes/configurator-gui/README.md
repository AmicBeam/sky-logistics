# 天穹配置器 GUI 交互原型

独立于模组代码的 260×250 显示尺寸可点击 HTML 原型，用于和 Minecraft 配置器 GUI 以相同尺寸确认布局、视觉状态和操作逻辑。内部保留 520×500 美术坐标，并以严格 0.5 倍显示，避免重新采样元素布局。

## 本地运行

```bash
npm install
npm run dev
```

打开 <http://localhost:3000/>。

## 已模拟的交互

- 线路首个、上一个、下一个/新建、末个和删除
- 线路名称输入
- 连接面列表按项目现有逻辑滚动：鼠标位于列表上时，每次滚轮移动一行
- 模式列使用项目已有的“抽取 / 存入”文字，并沿用游戏内模式文字配色
- 物品、流体、能量、自动四个独立开关
- 红石单按钮四态循环：忽略、有信号、无信号、禁用
- 留槽和优先级增减；按住 Shift 点击时步进 10
- 1×/2×预览、参考美术叠加和状态重置

参考图只用于可选对照层，实际交互界面由 HTML/CSS 控件组成。
