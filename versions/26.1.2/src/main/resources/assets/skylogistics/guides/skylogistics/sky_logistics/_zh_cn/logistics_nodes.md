# 节点与管道端点

<ItemLink id="sky_node" /> 是无线管道的端点。普通放置时默认存入，潜行放置时默认抽取。节点会贴在你点击的那一侧，只从那个方向访问相邻方块。

<RecipeFor id="sky_node" fallbackText="未找到天穹节点配方。" />

一次合成会得到 2 个节点。节点本身不存东西，只负责把同一条线路上的端点配对传输。

打开节点界面后，可以分别设置每一面：不连接、抽取或存入。只有连接好的面会参与线路；方块外观也会随连接和抽取状态变化。

节点还能选择搬运物品、流体或能量，设置目标优先级，并用红石控制开关。优先级高的存入端会优先接收。红石在忽略信号、有信号时工作、无信号时工作之间循环；被暂停的面不会被当成失败端点。

更多页面可设置红石、优先级、物品槽数与过滤。槽数 0 表示不限制。底部红色提示会说明无效组合，例如从外部网络抽取物品却没有具体物品白名单。
