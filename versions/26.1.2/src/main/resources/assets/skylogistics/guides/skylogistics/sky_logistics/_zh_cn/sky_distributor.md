# 天穹分配器

天穹分配器是仅供本模组简易管道与物流节点使用的无缓存物品、流体与能量路由代理。它不暴露通用 Forge/NeoForge 能力，因此原版漏斗和第三方管道不会连接。从六个相邻方块开始，它只沿容器继续搜索。节点或管道从分配器哪一面访问，全部绑定容器就统一从该面查询能力；BFS 路径与游标不会改变访问面。空气、普通方块、该入口面无可用能力的方块及其他分配器都会截断分支。目标上限默认为 16 个，服务器可通过 `[distributor].maxTargets` 在 1–64 间调整。

输入资源会在当前可接收的目标间尽量均分。轮转游标可在节点或管道预算令传输跨 tick 时维持长期公平。抽取会聚合全部目标，不要求均分。

每个实际接入面拥有独立目标缓存。放置时只预热已经相邻本模组管道或节点的面，其余面首次使用时惰性扫描，避免无条件执行六次 BFS。邻居变化会令全部面缓存失效，同时每 100 tick 做一次惰性能力变化保底校验。未完成的扫描会在后续 tick 继续，期间不会把已连接面误报为不可用。切换接入面会清除旧面的瞬时计划，但不会重置分配器共享的本 tick 传输预算。服务器可分别关闭物品、流体与能量联动。

模拟阶段生成有界传输计划，执行阶段直接复用而不重复扫描。`[distributor].scanOpsPerTick` 独立限制 BFS 每 tick 检查的位置数，默认保守设置为 16；`[distributor].opsPerTick` 只限制传输时的目标与容器内部槽位探测。两者都不与物流网络预算共享：网络只计一次端点访问，再由分配器执行有界内部路由。预算耗尽时资源留在来源，并在后续 tick 从游标位置继续。

手持天穹配置器并将准星对准分配器，会以青色边框高亮当前缓存内的全部目标容器。客户端只在切换所瞄准的分配器时立即请求快照，持续瞄准时每 20 tick 更新一次；渲染不会逐帧扫描容器。

它通过工作台制作：四角放海晶石，上下放青金石，左右放紫水晶碎片，中心放红石比较器，无需祭坛、尤洛伽水晶或天穹石。
