# 天穹配置器

<ItemLink id="configurator" /> 用于管理线路和快速复制节点设置。右击空气会打开配置器界面；打开界面时会退出粘贴模式。你可以在界面里切换线路，并选择是否搬运物品、流体和能量。

顶部的 |<、<、>+、>| 分别选择第一条、上一条、下一条或新建、最后一条线路。编辑线路名后按 Enter 或移开焦点即可重命名。× 只移除当前配置器的引用，不会删除其它设备。下方列表显示已加载连接面的模式、资源、优先级、红石、坐标和维度。

手持配置器潜行右击一个天穹物流节点，会复制该节点的线路和搬运开关，并直接进入粘贴模式。此时不会打开节点界面，快捷栏上方会显示已复制的线路名。

处于粘贴模式时，普通右击天穹物流节点会把配置器中的线路和搬运开关贴到该节点，同样不会打开节点界面。换掉手中的配置器、打开配置器界面，或潜行右击空气/非节点方块，都会退出粘贴模式。

配置器右击简易管道与机器相连的端点时，不会打开配置器界面，而是直接在抽取和存入模式之间切换。

物品、流体、能量、自动检测、红石、优先级和槽数控件会组成副手放置新节点时应用的预设。
