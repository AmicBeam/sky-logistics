# AStages 速率联动

如果整合包启用了 AStages 联动，线路持有者获得新的 stage 后，可以逐步提高无线节点、外部网络接口和简易管道每次搬运的数量。

物品、流体、Mekanism 化学品、FE、Botania mana、Ars Nouveau Source 与坚守者灵魂分别解锁。拥有多个 stage 时，会使用当前已解锁的最高数量，但仍不会超过设备和目标本身能处理的数量。

stage 提高的是每次搬运的数量，不会让节点工作得更频繁，也不会代替槽位并行升级。简易管道和目标设备自身的速度仍然有效。

无线线路通常跟随创建或认领它的玩家，简易管道跟随放置者。因此多人游戏中，不同玩家建立的线路可能拥有不同的解锁进度。
