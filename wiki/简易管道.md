# 简易管道

简易管道是无线节点之外的局部有线方案。物品、流体、能量管道只连接同类管道；相邻同类管道形成一条独立线路，不使用无线线路名。

## 连接与模式

- 管道会自动连接相邻同类管道和可用容器。
- 普通放置时，玩家点击的容器侧默认为存入端。
- 潜行放置时，点击侧默认为抽取端。
- 其它自动发现的容器连接默认为存入。
- 抽取连接使用更宽的视觉套环。

## 工具操作

- 天穹扳手普通右击某一侧：断开或重新连接该侧。
- 天穹扳手潜行右击管道：快速拆除，掉落优先进入背包。
- 天穹配置器右击机器端点：在抽取与存入之间切换。

## 端点过滤

- 对准管道面向机器的端点，手持天穹过滤列表、天穹标签过滤列表或天穹模组过滤列表右击，会把列表规则复制到该端点，不消耗列表物品。
- 过滤按端点独立保存；抽取端限制可取出的资源，存入端限制可送入的资源。
- 标签过滤列表可分别配置物品标签和流体标签。
- 模组过滤列表按被传输资源的 ID 命名空间匹配；FE 使用统一虚拟 ID `forge`。能量管道只接受模组过滤列表。
- 空手潜行右击同一端点可清除过滤。
- 安装 Jade 后，对准端点可查看该端点的传输状态与过滤摘要；保持潜行可展开具体过滤内容。普通物流节点也支持潜行展开过滤内容。

当 AE2 或精致存储存在时，本模组不会重复注册天穹扳手，可使用对应模组兼容扳手。

## [[默认限速|AStages联动]]

下表数值都是单次搬运上限。服务器启用 [[AStages 联动|AStages联动]]后，还会按管网持有者的 stage 施加上限；实际值取两者中较低者。

| 管道 | 每个抽取端每 tick [[默认上限|AStages联动]] | 配置项 |
| --- | ---: | --- |
| 物品 | 64 个；一次最多一个来源槽和一个目标槽 | `simpleItemPipeTransferRate` |
| 流体 | 10,000 mB | `simpleFluidPipeTransferRate` |
| 能量 | 100,000 FE | `simpleEnergyPipeTransferRate` |
| 流体管道中的 Mek 化学品 | 10,000 | `simpleChemicalPipeTransferRate` |
| 能量管道中的 Botania mana | 50 | `simpleManaPipeTransferRate` |
| 能量管道中的 Ars Source | 50 | `simpleSourcePipeTransferRate` |

Mana 默认值按近距离普通 Mana Spreader 的平均每 tick 吞吐取整；Source 默认值等于普通 Source Relay 每 20 tick 搬运 1,000 Source 的平均吞吐。

## 线路规模

一条相连管道线路默认最多 256 个管道方块。新放置或重新连接会使网络超过上限时，新边保持断开并显示提示。管理员可通过 `simplePipeMaxConnectedBlocks` 调整 16–65,536。

## 禁用开关

管理员可分别关闭物品、流体、能量管道的连接与传输：

- `enableSimpleItemPipe`
- `enableSimpleFluidPipe`
- `enableSimpleEnergyPipe`

关闭后方块仍然存在，但不会连接对应能力或搬运资源。
