# 简易管道

简易管道是无线节点之外的局部有线方案。物品、流体、能量管道只连接同类管道；相邻同类管道形成一条独立线路，不使用无线线路名。

## 连接与模式

- 管道会自动连接相邻同类管道和可用容器。
- 普通放置时，玩家点击的容器侧默认为存入端。
- 潜行放置时，点击侧默认为抽取端。
- 其它自动发现的容器连接默认为存入。
- 抽取连接使用更宽的视觉套环。

## 工具操作

- 天穹扳手普通右击某一侧：断开或重新连接该侧。
- 天穹扳手潜行右击管道：快速拆除，掉落优先进入背包。
- 天穹配置器右击机器端点：在抽取与存入之间切换。

当 AE2 或精致存储存在时，本模组不会重复注册天穹扳手，可使用对应模组兼容扳手。

## 默认限速

| 管道 | 每个抽取端每 tick 默认上限 | 配置项 |
| --- | ---: | --- |
| 物品 | 64 个；一次最多一个来源槽和一个目标槽 | `simpleItemPipeTransferRate` |
| 流体 | 10,000 mB | `simpleFluidPipeTransferRate` |
| 能量 | 100,000 FE | `simpleEnergyPipeTransferRate` |
| 流体管道中的 Mek 化学品 | 10,000 | `simpleChemicalPipeTransferRate` |
| 能量管道中的 Botania mana | 100,000 | `simpleManaPipeTransferRate` |
| 能量管道中的 Ars Source | 100,000 | `simpleSourcePipeTransferRate` |

## 线路规模

一条相连管道线路默认最多 256 个管道方块。新放置或重新连接会使网络超过上限时，新边保持断开并显示提示。管理员可通过 `simplePipeMaxConnectedBlocks` 调整 16–65,536。

## 禁用开关

管理员可分别关闭物品、流体、能量管道的连接与传输：

- `enableSimpleItemPipe`
- `enableSimpleFluidPipe`
- `enableSimpleEnergyPipe`

关闭后方块仍然存在，但不会连接对应能力或搬运资源。
