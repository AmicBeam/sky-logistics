# 配置说明

服务端配置决定世界规则与性能预算；客户端配置只影响本地显示。配置文件名会随加载器和版本略有不同，建议先启动一次游戏生成文件。

## 仓库

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `maxVaultTypes` | 36 | 甘露可扩展到的最大物品/流体类型数，范围 1–63 |
| `maxVaultItemEntryNbtBytes` | 8192 | 单个不同物品条目允许的最大序列化数据字节数 |
| `maxVaultFluidEntryNbtBytes` | 4096 | 单个不同流体条目允许的最大序列化数据字节数 |

## 传输与性能

下表中的单次传输上限与每 tick 操作预算是不同维度。可选的 [[AStages 联动|AStages联动]]只限制六种资源的单次搬运量，不改变操作预算或工作频率。

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `nodeItemTransferLimit` | 2,147,483,647 | 普通节点[[单次物品传输上限|AStages联动]] |
| `nodeEnergyTransferLimit` | 2,147,483,647 | 普通节点[[单次 FE 传输上限|AStages联动]] |
| `skyContainerTransferLimit` | 9,223,372,036,854,775,807 | 支持 long 的存储端点之间[[单次直连传输上限|AStages联动]]（如天穹仓库、AE2、Beyond Dimensions） |
| `serverOpsPerTick` | 2048 | 全服务器每 tick 操作预算 |
| `lineOpsPerTick` | 256 | 单线路每 tick 操作预算 |
| `endpointTargetAttempts` | 1 | 一个来源候选每次最多尝试的目标数 |
| `externalTankScansPerEndpoint` | 8 | 每端点每 tick 最多扫描的外部流体槽数 |
| `sourceSearchAttemptsPerEndpoint` | 64 | 一次传输寻找工作时最多跳过的位置数 |
| `maxItemSlotLimit` | 36 | 节点面可设置的最大物品保留数量；面值 0 表示不限 |

提高预算会增加大型网络吞吐，也可能增加服务器单 tick 开销。它与 [[AStages 单次搬运量限制|AStages联动]]相互独立；建议一次只调整一个指标并观察 MSPT。

## 简易管道

这些数值是管道自身的单次搬运上限。启用 [[AStages 联动|AStages联动]]后，实际值取管道上限和当前 stage 上限中的较低值。

| 配置项 | 默认值 |
| --- | ---: |
| `enableSimpleItemPipe` | `true` |
| `enableSimpleFluidPipe` | `true` |
| `enableSimpleEnergyPipe` | `true` |
| `simpleItemPipeTransferRate` | 64 |
| `simpleFluidPipeTransferRate` | 10,000 mB/t |
| `simpleEnergyPipeTransferRate` | 100,000 FE/t |
| `simpleChemicalPipeTransferRate` | 10,000/t |
| `simpleManaPipeTransferRate` | 100,000/t |
| `simpleSourcePipeTransferRate` | 100,000/t |
| `simplePipeMaxConnectedBlocks` | 256 |

## AStages

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `transfers.astages.enabled` | `false` | 是否启用按线路持有者 stage 限制单次搬运量 |
| `transfers.astages.initialRates` | 六资源字典 | 未解锁 stage 时的物品、流体、化学品、FE、mana、Source 上限 |
| `transfers.astages.stageRates` | `[]` | stage 解锁字典列表；除 `stage` 外六个资源字段都可省略 |

完整格式、多人线路归属和计算规则参见 [[AStages 联动|AStages联动]]。

## 天穹分配器

配置文件内对应独立的 `[distributor]` 分类。

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `maxTargets` | 16 | 单个分配器最多连接的容器数，范围 1–64；提高后会增加扫描与代理操作开销 |
| `scanOpsPerTick` | 16 | 单个分配器每 tick 最多检查的 BFS 位置数，范围 1–4,096；只用于目标发现，不占用网络或分配传输预算 |
| `opsPerTick` | 64 | 单个分配器每 tick 最多执行的传输探测数，范围 1–4,096；一个目标及其首个槽位合计 1 次，同一目标的后续槽位各计 1 次，不与 BFS 或物流网络预算共享 |
| `enableItems` | true | 是否联动物品容器 |
| `enableFluids` | true | 是否联动流体容器 |
| `enableEnergy` | true | 是否联动能量容器 |

## 第三方联动开关

AE2、精致存储、Beyond Dimensions、Mekanism、Botania 和 Ars Nouveau 的资源路径都有独立 `allow...Transfer` 开关。关闭某一路径只禁用该资源联动，不会卸载方块或破坏已保存的网络。

常见示例：

- `allowAe2ItemTransfer` / `allowAe2FluidTransfer`
- `allowRefinedStorageItemTransfer` / `allowRefinedStorageFluidTransfer`
- `allowBeyondDimensionsItemTransfer` / `FluidTransfer` / `EnergyTransfer`
- `allowFluidChemicalTransfer`
- `allowEnergyManaTransfer`
- `allowEnergySourceTransfer`
