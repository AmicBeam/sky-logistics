# 联动与版本差异

## 版本概览

| 功能 | 1.20.1 Forge | 1.21.1 NeoForge | 26.1.2 NeoForge |
| --- | --- | --- | --- |
| 无线节点、仓库、管道、祭坛 | 支持 | 支持 | 支持 |
| Patchouli | 支持，基础词条 | 支持，基础词条 | 兼容 |
| GuideME | 不支持 | 不支持 | 完整中英文手册 |
| 手册物品 | 已注册 | 未注册 | 安装 GuideME/Patchouli 时显示 |
| Jade / JEI | 可选 API 构建 | 可选 API 构建 | 可选 API 构建 |
| Botania mana | 支持 1.20.1 联动 | 取决于兼容 API | 当前版本能力检测决定 |

所有功能性内容在三个版本保持对应实现；加载器 API、标签名和配方 JSON 格式会随 Minecraft 版本不同。

## AE2

- 天穹 ME 接口可访问 AE2 物品和流体网络。
- 可配置是否允许物品、流体传输。
- 安装 AppFlux、Applied Mekanistics、Applied Botanics、Ars Énergistique 等兼容附属时，可按各自配置开关搬运 FE、化学品、mana 或 Source。
- 相关附属不存在时不会启用对应路径。

## Refined Storage

- 天穹 RS 接口访问 RS 网络的物品和流体。
- 物品、流体开关彼此独立。

## Beyond Dimensions

- 天穹维度网络接口访问该模组网络中的物品、流体和 FE。
- 同时安装 Mekanism 或 Ars Nouveau 时可增加化学品或 Source 路径。
- 每种资源都有独立的服务端联动开关。

## Mekanism、Botania 与 Ars Nouveau

- Mekanism 化学品沿“流体”资源开关与简易流体管道工作。
- Botania mana 和 Ars Nouveau Source 沿“能量”资源开关与简易能量管道工作。
- 这些资源只会在同类能力之间搬运，不会转换为 FE，也不会互相转换。

## Curios 与 Sophisticated Backpacks

- Curios 存在时，天穹项链可在饰品栏工作。
- 没有 Curios 时，项链仍可从玩家主物品栏工作。
- Sophisticated Backpacks 存在时，项链可以按兼容规则访问支持的背包库存。

## Jade 与 JEI

- Jade 显示节点、仓库、祭坛与供桌的有用状态；空供奉槽不会显示多余信息。
- JEI 显示默认合成与供奉配方，并支持向过滤界面拖入 ghost 物品/流体。
