# 原版进度联动

Sky Logistics 的所有支持版本默认根据线路持有者完成的 Minecraft **Advancement（进度）**，限制并逐步解锁物流系统的单次搬运量。该功能不依赖第三方模组，可通过 `enabled = false` 关闭。

## 配置示例

配置位于服务端配置的 `transfers.advancements` 分类：

```toml
[transfers.advancements]
enabled = true
advancementRates = [
  { advancement = "minecraft:story/upgrade_tools", items = 16, fluids = 2500, chemicals = 2500, energy = 25000, mana = 25000, source = 25000 },
  { advancement = "minecraft:story/mine_diamond", items = 64, fluids = 10000, chemicals = 10000, energy = 100000, mana = 100000, source = 100000 },
  { advancement = "minecraft:end/elytra", items = "unlimited", fluids = "unlimited", chemicals = "unlimited", energy = "unlimited", mana = "unlimited", source = "unlimited" }
]

[transfers.advancements.initialRates]
items = 4
fluids = 625
chemicals = 625
energy = 6250
mana = 6250
source = 6250
```

1. 系统从 `initialRates` 取得各资源初始上限。
2. 查找线路持有者已完成且出现在 `advancementRates` 中的所有进度。
3. 每种资源取初始值和所有已完成进度配置值中的最高值。
4. 最终搬运量仍与管道、节点、目标接收能力及其它已启用进度联动的上限取最低值。

`advancement` 必须填写完整资源 ID，例如 `minecraft:story/enter_the_nether`，数据包或模组进度也可使用其命名空间 ID。不同资源可独立解锁；1.21.1 还支持 `souls`。

默认档位依次为“来硬的”16/t、“钻石！”64/t、“附魔师”256/t、“星际商人”1,024/t、“带信标回家”4,096/t、“信标工程师”16,384/t，最后由“天空即为极限”解锁为不限速。流体类按物品的 156.25 倍、能量类按 1,562.5 倍配置。解锁条目的任意资源都可直接填写字符串 `"unlimited"`，无需手写 `Long.MAX_VALUE`。

启用时，进度菜单会出现串行的“天穹物流”页，展示默认里程碑及其解锁速率；玩家登录或取得任意进度时同步完成状态。Jade 仅在当前进度速率低于该简易管道或物流节点的配置上限时显示；达到设备当前配置上限后立即隐藏，不必等到最终不限速档位。

无线线路按创建或认领线路的持有者判断，简易管网按放置者或继承到的管网持有者判断。当前仅在持有者在线时读取原版进度；持有者离线、线路无持有者、ID 无效或查询失败时安全使用 `initialRates`。查询结果按“玩家 + 游戏 tick”缓存。

原版进度联动控制的是**每次操作的搬运量**，不会改变速度升级、操作频率或服务器/线路每 tick 预算。它与 AStages 可独立启用；两者同时启用时取更严格的上限。
