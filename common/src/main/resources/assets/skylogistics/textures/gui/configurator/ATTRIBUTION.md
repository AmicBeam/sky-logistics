# Configurator GUI texture attribution

- `redstone_high.png`, `redstone_low.png`, `redstone_ignore.png`, and
  `redstone_disabled.png` use CoFH Core's redstone GUI icon family. CoFH assets
  are distributed under CC BY-SA 4.0:
  https://oldcofh.github.io/permissions/
- `resource_*.png` and `resource_*_small.png` are Sky Logistics configurator
  artwork derived from this project's approved HTML prototype.

The local state mapping is:

- Sky Logistics `IGNORE` -> CoFH `icon_redstone_off`
- Sky Logistics `HIGH` -> CoFH `icon_redstone_on`
- Sky Logistics `LOW` -> CoFH `icon_rs_torch_off`
- Sky Logistics `DISABLED` -> CoFH `icon_nope`
