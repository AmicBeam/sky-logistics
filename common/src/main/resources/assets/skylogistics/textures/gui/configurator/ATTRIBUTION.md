# Configurator GUI texture attribution

- `redstone_high.png`, `redstone_low.png`, and `redstone_ignore.png` are from
  Mekanism's redstone control GUI textures. Mekanism is distributed under the
  MIT License: https://github.com/mekanism/Mekanism
- `redstone_disabled.png` is based on CoFH Core's redstone-off GUI icon. CoFH
  assets are distributed under CC BY-SA 4.0:
  https://oldcofh.github.io/permissions/
- `resource_*.png` and `resource_*_small.png` are Sky Logistics configurator
  artwork derived from this project's approved HTML prototype.

The local state mapping is:

- Sky Logistics `IGNORE` -> Mekanism `redstone_control_disabled`
- Sky Logistics `HIGH` -> Mekanism `redstone_control_high`
- Sky Logistics `LOW` -> Mekanism `redstone_control_low`
- Sky Logistics `DISABLED` -> CoFH `icon_redstone_off`
